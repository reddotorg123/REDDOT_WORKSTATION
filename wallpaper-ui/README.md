# Jagadish K — Live Cyber Animated Wallpaper

An independent, standalone, high-performance **Cyberpunk Live Animated Laptop Wallpaper** project designed for **Windows Lively Wallpaper**, **Wallpaper Engine**, or standalone fullscreen execution.

## Features
- **3D Interactive Lanyard ID Card Badge**: Physics-based 3D tilt tracking with spring dampening, holographic sheen, and idle floating oscillation.
- **Dynamic PCB Circuit Board Canvas**: 60–120 FPS hardware traces with glowing electrical pulse packets, solder junctions, and binary rain streams.
- **Real-Time HUD Digital Clock**: 12/24-hour clock with milliseconds, day, date, and live session uptime.
- **Hardware Telemetry Simulation**: Real-time ESP32 MCU frequency load, SRAM allocation, and Pulse-Echo ultrasonic NDT waveform monitor.
- **16+ Hackathon Wins Carousel**: Auto-cycling stream of all 16+ verified awards with prize money and venues.
- **6 Cyber Neon Themes**: Cyber Obsidian, Matrix Emerald, Crimson REDDOT, Cyberpunk Amber, Quantum Violet, and Neon Electric.
- **3 Display Modes**: Full Cyber HUD, Minimalist Clock, and Badge Focus.
- **Web Audio Synthesizer**: Generative ambient sci-fi soundscape (toggleable via `M` or UI button).
- **Windows Lively Wallpaper Ready**: Includes `LivelyInfo.json` for one-click drag-and-drop import.
