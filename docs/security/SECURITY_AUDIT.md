# REDDOT Workstation — Security Audit & Remediation Matrix

**Date**: November 2026  
**Auditor**: Principal Cybersecurity Engineer (Automated & Manual Review)  

---

## 1. Vulnerability Findings & Remediation Plan

### Issue SEC-01: Unrestricted Shell Execution in Terminal IPC
- **Severity**: HIGH
- **Location**: `main.js` (IPC channel `terminal-exec`)
- **Vulnerability**: Renderer sends raw string commands to `child_process.exec(cmd)`. If compromised via XSS or malicious payload, arbitrary OS commands could be executed with current user privileges.
- **Remediation**:
  - Replace `exec(rawString)` with a strict allowlist of development & workstation utilities (`git`, `npm`, `node`, `ping`, `dir`, `echo`).
  - Sanitize arguments, enforce a strict command timeout (30 seconds), and prohibit directory traversal escapes.
- **Status**: Remediation Planned (Phase 6).

### Issue SEC-02: Hardcoded Fallback Credentials & User Roles
- **Severity**: MEDIUM
- **Location**: `react-app/src/components/MessagesView.jsx`, `firebaseBridge.js`
- **Vulnerability**: Fallback user profile `jagadish2k2006@gmail.com` with hardcoded ID `RD-FOUNDER-001` was used when authentication profile was partially initialized.
- **Remediation**:
  - Strictly derive sender identity and role privileges from `firebaseBridge.activeUser` verified by Firebase Auth tokens.
  - Reject unauthorized dispatch if user is not signed in.
- **Status**: Remediation Planned (Phase 3).

### Issue SEC-03: Localhost Microservice Exposure
- **Severity**: LOW
- **Location**: `backend/server.js` (Port 5050)
- **Vulnerability**: Express server bound to port 5050 lacked shared secret authentication headers, permitting any local process to query attachment metadata.
- **Remediation**:
  - Introduce an ephemeral token generated by Electron `main.js` on startup and passed to the backend, verifying `X-Workstation-Token` on every request.
- **Status**: Remediation Planned (Phase 6).

### Issue SEC-04: Secrets in Repository Hygiene
- **Severity**: RESOLVED
- **Status**: `service-account.json` and `gdrive_tokens.json` were untracked and shielded in `.gitignore`. No private keys or service account credentials are committed in git.
